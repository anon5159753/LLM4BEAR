# Code Contents in Order

1. Zero_Few_Baselines.ipynb: Using BundleRec and LLM4BEAR datasets for bundle generation. Zero/Few-shot bundle generation experiments are completed for various LLMs.
2. running_AICL.ipynb: Using BundleRec and LLM4BEAR datasets with state-of-the-art bundle generation model AICL.
3. SFT.ipynb: Using OpenAI's fine-tuning service to train GPT-4o-mini and GPT-4.1-mini models using BundleRec and LLM4BEAR datasets before generating bundles.
4. Comparing_Baselines.ipynb: Analysing all the LLM-baselines.
